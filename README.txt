How to preview:
Open index.html in a browser. For public phone access, upload the whole folder to a static web host.

Important:
This version intentionally has no public Admin/Edit screen. A truly secure web-based admin editor requires a server/backend or authenticated external data service. Static files alone cannot safely provide admin-only writes.
